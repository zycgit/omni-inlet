# Privacy policy

OmniInlet is a local desktop capture tool. The current release records only the
window explicitly selected by the operator and writes the resulting video and
job metadata to the output directory selected by that operator.

OmniInlet does not transmit captured content, window information, job metadata,
diagnostics, or any other information to networked systems. Network transfer can
only occur when the operator explicitly uses a future connector or processing
feature that identifies its destination and requests that transfer.

The operator is responsible for obtaining any consent required to record a
window and for protecting, retaining, and deleting the resulting local files.
Deleting the capture job directory removes the data produced by that job.

Third-party libraries bundled with the portable application run locally and do
not add telemetry to OmniInlet. GitHub and SignPath process build and signing
metadata when project maintainers create releases; they do not receive captured
user content.

Questions and security reports can be submitted through the project's GitHub
issue tracker: <https://github.com/zycgit/omni-inlet/issues>.
